# Аутсорс модулей

[[00 — Makora]] · [[02 — Проекты и задачи]] · [[06 — Рабочие копии и сборка]] · [[07 — Дашборд CLI и данные]]

Самостоятельный модуль можно поручить внешнему исполнителю через переносимое ТЗ и контракт OpenAPI. Для работы исполнителю достаточно согласованных файлов и синтетических примеров. Дашборд ведёт передачу результата от подготовки до переноса в проект.

1. `outsource.create` сохраняет цель, контекст, границы, критерии, OpenAPI 3.0/3.1 и целевой относительный путь. Путь должен обозначать новый каталог с существующим родителем в проекте.
2. Через вкладку «Аутсорс» можно скачать ТЗ и OpenAPI. ТЗ строится из введённых полей. Перед внешней передачей проверь, что вложения и примеры согласованы.
3. Исполнитель возвращает ZIP с `outsource.json`, `openapi.json` и содержимым `module/` в корне. Формат `outsource.json` задаёт секция `returnZip` экспортированного ТЗ.
4. Импорт проверяет структуру, контракт, пути и лимиты размера. Максимум — 10 МиБ для ZIP, 32 МиБ в распакованном виде и 512 записей. Файлы доступны в промежуточной папке, которую видно в карточке. До приёмки архив можно заменить.
5. После ревью `outsource.accept` сохраняет доказательство и хеш конкретного архива. `outsource.integrate` сверяет принятые файлы и переносит `openapi.json` и `module/` в выделенный каталог проекта. Повтор того же подтверждённого действия идемпотентен.

Карточка проходит состояния `prepared → imported → accepted → integrated`. Подключение модуля к приложению, вызов через согласованный API и его интеграционные тесты ведутся как обычная задача. Ошибки смотрят через локальный API и аудит.
