# Приём идеи из чата Codex

Применяй к явной просьбе сохранить идею для локального проекта. Запрос может прийти во время любой фазы, в исходном или в другом чате.

1. Найди проект по явно переданному пути или текущему рабочему каталогу. Прочитай `control.cjs state` и проверь совпадение проекта. Зарегистрируй проект лишь при однозначном выборе пользователя.
2. Сохрани исходную формулировку как `text` без переписывания. Проверь существующую очередь идей, задачи и текущую фазу.
3. Предложи момент реализации в `proposal`. Для исправления, блокирующего текущую приёмку, предложи текущий срез и назови нарушенный критерий. Для расширения активной области предложи следующую итерацию после конкретного тикета, если зависимость подтверждена. Для остального укажи подходящий этап или оставь решение открытым. При известной зависимости запиши ID в `afterTaskId`.
4. Передай `idea.add` через локальный `control.cjs action`. При повторе сохрани существующий ID и сообщи, что идея уже есть. Верни ID, ссылку на дашборд и предложение по этапу.
5. При продолжении работы проверь `decision`. Только принятое решение переводит идею в план. Пересмотри критерии и зависимости в `to-tickets` перед поручением OpenCode. Отложенная идея остаётся видимой.

Приём идеи означает запись в SQLite и предложение по сроку. Он не запускает исполнителей и не меняет текущий контракт.
