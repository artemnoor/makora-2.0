# История версий

## Текущая ветка main

- Вложенные лаборатории получили версионированные планы, батчи по зависимостям, составные артефакты и приёмку из текущего чата Codex.
- Панель сохраняет запросы ревью, результаты и лимиты. Восстановление опирается на SQLite, журналы попыток и состояние сессий OpenCode.
- Светлый дашборд включает вкладку аутсорса с ТЗ, OpenAPI и проверяемым импортом ZIP.
- Добавлены связанная база знаний Obsidian, снимки работающей панели и Windows CI для штатного набора тестов.

## v2.1.0

- Codex синхронизирует с Makora данные файла и фреймов, прочитанные через официальный плагин Figma. Второе подтверждение открывается после синхронизации конкретного макета.
- Навык `model-prompt-profile` описывает создание и проверку профиля для выбранной модели с учётом официальной документации и пользовательского опыта.
- Руководство содержит быстрый старт, схему работы и снимки локального интерфейса.

## v2.0.0

- Первый публичный снимок Makora. Включает дашборд, E Verified Batch, изолированные worktrees, очередь идей, лаборатории и процесс согласования дизайна. [Первый публичный коммит](https://github.com/artemnoor/makora-2.0/commit/5cfe20af1bbfa0ea2298526dd25b04d45b662975)
